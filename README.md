# 에어컨 무료 견적 (1차 홈페이지 시제품)

고객이 설치 조건을 입력하면 브랜드별 제품가 + 설치비 총액을 즉시 계산하고, 입력 조건에 맞는 모의 설치 플랜을 보여 주는 단일 페이지 시제품입니다. 기획서(2026-10-08) 1차 범위 기준입니다.

## 입력 항목
1. 거주 형태 (아파트·오피스텔 / 주택·빌라)
2. 설치 대수 1~4대, 대당 설치 공간과 평수
   - 1~2대: 10평 이하 벽걸이, 11평 이상 스탠드
   - 3대 이상: 시스템 에어컨 (천장형 실내기 + 실외기 1대, 천장 점검구·드레인 배관 포함)
3. 거주지 주소 (부동산 플랫폼 연동 후 단지 구조 자동 파악 예정)
4. 거주 여부 (공실 / 거주 중)
5. 추가 옵션 (부분 도배, 냉매 보충, 전기 작업, 기존 철거, 실외기 앵글, 사다리차)

## 결과
- 삼성·LG·캐리어·위니아 브랜드별 총액 범위와 설치비 항목 내역
- 입력 조건만으로 만든 모의 설치 플랜 (실내기·실외기 위치, 배관 경로, 주의사항)
- 브랜드 선택 → 예약 신청 → 기사 알림 미리보기 (동까지 공개, 정산 금액 = 설치비의 95%)

## 파일
- `index.html` 단일 파일. 외부 의존성은 Google Fonts뿐이라 어디에 올려도 동작합니다.
- 단가는 스크립트 상단 `RATES`, 브랜드 모델·가격은 `BRANDS`에서 수정합니다. 단가표의 "가정" 표시 항목은 지역 기사 인터뷰 후 확정해야 합니다.
- 예약 데이터는 브라우저 로컬 저장소에만 저장됩니다. 실제 운영에는 서버 DB와 알림톡 발송이 필요합니다.
