# 속시원 · 에어컨 무료 견적 (1차 홈페이지 시제품)

조건만 고르면 금액이 바로 나오는 에어컨 견적 홈페이지입니다. 기획서(2026-10-08) 1차 범위 기준이며, 첫 페이지에서 네 가지 견적으로 나뉩니다.

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 로고 + 설치 견적 / 청소 견적 / 냉매 충전 / 이전·설치 버튼 4개 |
| `install.html` | 구매+신규 설치. 거주 형태, 대수·평수, 주소, 거주 여부, 옵션 → 브랜드별 총액, 모의 설치 플랜, 예약 |
| `clean.html` | 분해 청소. 기종, 대수, 사용 연수, 높이, 실외기 세척·팬 분해 → 금액, 예약 |
| `gas.html` | 냉매 충전. 기종, 냉매 종류, 제조 연도, 증상 → 금액, 예약 |
| `move.html` | 이전 설치. 기종, 대수, 거리, 도착지 조건, 배관·앵글·철거 → 금액, 예약 |
| `prices.html` | 단가표 전체 공개, 약속, 진행 절차, FAQ |
| `recruit.html` | 설치 기사 모집 (알림 예시, 등록 조건, 신청 폼) |
| `admin.html` | 관리자 미리보기 (이 브라우저에서 접수한 예약·기사 신청) |
| `css/style.css` | 공통 스타일 |
| `js/common.js` | 단가(`RATES`), 브랜드 모델·가격(`BRANDS`), 상단·하단 바, 예약 접수와 기사 알림 미리보기 |

## 계산 규칙
- 설치 1~2대: 10평 이하 벽걸이, 11평 이상 스탠드. 2대째부터 기본 설치비 10% 할인
- 설치 3대 이상: 시스템 에어컨 (천장형 실내기 + 실외기 1대, 천장 점검구·드레인 배관 포함)
- 희망일이 6~8월이면 시공비에 성수기 계수 1.1
- 기사 정산 금액 = 시공비 − 중개 수수료 5%

## 수정 위치
- 단가: `js/common.js`의 `RATES`. 단가표의 "가정" 항목은 지역 기사 인터뷰 후 확정해야 합니다.
- 브랜드 모델과 판매가: `js/common.js`의 `BRANDS` (모두 예시)
- 상담 전화, 카카오톡 채널, 사업자 정보: `index.html`, `js/common.js`의 푸터

## 참고
- 외부 의존성은 Google Fonts뿐이라 어디에 올려도 동작합니다.
- 예약 데이터는 브라우저 로컬 저장소에만 저장됩니다. 실제 운영에는 서버 DB와 알림톡 발송이 필요합니다.
